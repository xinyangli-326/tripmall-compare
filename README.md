# 携程服务市场 · 采购比价小助手

给酒店采购用的**同品类跨供应商比价**网页。数据来自携程 eBooking 服务市场的「服务市场」（上海站）。

## 怎么用

打开 `index.html` 即可（纯静态，无构建、无依赖）。

- 首页搜索：输入品类 / 商品 / 规格，或点常用品类
- 左侧三个下拉：一级 → 二级 → 三级类目级联筛选
- 主表：每行一个规格，按**换算单价**排序（点表头可切换升降序）
- 点「共 N 档」展开同一商品的全部档位；点图片看大图
- 点「点击跳转商品链接」在携程打开对应商品页下单
- 点每行左侧 `＋` 加入**选货单**，右侧浮标可改数量、算总价、提示"有更便宜的"

## 目录

| 路径 | 说明 |
|---|---|
| `index.html` | 整个网站（单文件，含样式与逻辑） |
| `data/site-summary.json` | 品类 / 供应商汇总、各品类价格带（首屏用，0.3MB） |
| `data/site-rows.json` | 全部 SKU 明细，29,436 行 |
| `data/raw-specs.json` | 抓取原始数据（备份，重建用） |
| `data/raw-pay.json` | 各商品可用支付方式（备份） |
| `tools/` | 抓取与生成脚本 |

## 口径说明

**价格**：接口返回的 `price` 是单价，`minQuantity` 是起订量。
规格名里的 `【N*单位】`：N 等于起订量时它是起订量；起订量为 1 且 N>1 时该价格是整包价，需 ÷N。
当两者有歧义时，**用同一商品里无歧义的档位做校准**判断。

**换算单价**（横向比价用）：洗沐/饮料 → 元/100ml；皂/茶/粉 → 元/100g；卷纸 → 元/卷；抽纸 → 元/抽；
湿巾 → 元/片；马桶垫纸 → 元/张；拖鞋 → 元/双；家具/电器/布草/其余 → 元/件。

**不进比价的档位**：
- 拿样 / 寄样 / 体验装 → 商品标「可0元试用」
- 差价 / 协议价 / 专拍 / 店铺公告 → 标「公告 / 非商品」
- 配件档（电池 / 支架 / 数据线 / 滤芯等，只在同商品另有主体档时才判定）
- 规格名里没有量、算不出统一单价的 → 标「按件」

**适用酒店**：取自商品参数「适用酒店」，0-2星 / 0-3星 / 2-4星 / 3-4星 / 3-5星。

**支付方式**：现金与生意通支付为基础，免房支付 / 预付分期 / 客房分成 / 0元购按接口逐商品判定（共 78 个商品支持特殊支付）。

## 怎么更新数据

1. 双击源目录的 `start.bat` 启动已登录的调试 Edge（端口 9333）
2. 依次运行：
   ```bash
   node tools/fetch-specs-full.mjs   # 全库抓套餐（含 minQuantity），约 10~15 分钟
   node tools/fetch-pay.mjs          # 抓支付方式，约 2 分钟
   node tools/build-site.mjs         # 生成 data/site-*.json
   node tools/audit.mjs              # 自检报告 → work/audit.md
   ```

抓取必须在本机浏览器完成（云端 IP 登录会被风控）。

## 部署

纯静态，把整个目录传到任意静态托管即可：

- **GitHub Pages**：仓库 Settings → Pages → 选 `main` 分支根目录
- **Vercel**：Import 仓库，框架选 Other，直接 Deploy
- **Gitee Pages / 腾讯云 COS / 阿里云 OSS**：把 `index.html` 和 `data/` 传上去即可（国内访问更快）

无需任何构建命令与环境变量。
